## 前言

新设备配环境是程序员的共性痛点，结合 [dotfiles](https://github.com/liuyuxuan0723/dotfiles) 和配置脚本可快速搭建开发环境。

> 直接替换 dotfile 时部分配置可能不生效（如未安装字体）。私人电脑用 macOS 自带的「迁移助理」更省事。

## 命令行工具

### Homebrew

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

### Git

```bash
brew install git

git config --global user.name "your-name"
git config --global user.email "your@email.com"

ssh-keygen -t ed25519 -C "your@email.com"
cat ~/.ssh/id_ed25519.pub
```

> 新设备推荐用 `ed25519`，比 RSA 更短更快。

### Oh My Zsh + Powerlevel10k

```bash
# 安装 oh-my-zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

# 安装 Powerlevel10k
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git "${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k"
echo 'ZSH_THEME="powerlevel10k/powerlevel10k"' >> ~/.zshrc

# 安装插件
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

在 `~/.zshrc` 中启用插件：`plugins=(git zsh-autosuggestions zsh-syntax-highlighting)`

### K8s 相关

```bash
brew install kubernetes-cli k9s kubecm kube-ps1
```

- [k9s](https://k9scli.io/) - 终端 K8s 管理
- [kubecm](https://github.com/sunny0826/kubecm) - 多集群 kubeconfig 管理
- [kube-ps1](https://github.com/jonmosco/kube-ps1) - 在 prompt 显示当前 context

### 常用 CLI

```bash
brew install yq  # JSON/YAML 解析
```

## 开发环境

### Miniconda

```bash
brew install --cask miniconda
```

### Go（多版本管理 g）

```bash
curl -sSL https://raw.githubusercontent.com/voidint/g/master/install.sh | bash
source "$HOME/.g/env"
```

若与 oh-my-zsh 的 `g` 别名冲突，在 `~/.zshrc` 中加：`unalias g 2>/dev/null`

### Node（多版本管理 n）

```bash
curl -fsSL https://raw.githubusercontent.com/tj/n/master/bin/n | bash -s lts
npm install -g n  # 后续用 n 切换版本
```

### Java（多版本管理）

[sdkman](https://sdkman.io/) 更常用：

```bash
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install java 17-tem
```

## 配置脚本

基于 dotfiles 仓库的脚本：

| 脚本 | 用途 |
|------|------|
| `./brew.sh` | 批量安装 brew 包 |
| `./config.sh` | 应用配置 |
| `./syncToRemote.sh` | 本地 dotfile → 远端 |
| `./syncToLocal.sh` | 远端 → 本地 dotfile |

**一键执行**：`./brew.sh && ./config.sh && ./syncToLocal.sh`

> 同步前检查需同步的目录；Git LFS 单文件超过 2MB 时可能受限。

## macOS 快捷操作

iTerm2 快速唤起（可用于 Alfred / Raycast / 快捷指令）：

```applescript
on run {input, parameters}
	tell application "System Events"
		set isRunning to (count of (every process whose name is "iTerm2")) > 0
	end tell

	if not isRunning then
		tell application "iTerm"
			activate
			create window with default profile
		end tell
	else
		tell application "iTerm"
			activate
			if (count of windows) = 0 then create window with default profile
		end tell
	end if

	return input
end run
```
